Project 1: "The Line-Follower with Regenerative Braking" (Power Electronics Focus)
Why this sells: Most line-followers are brain-dead simple (just IR sensors and PID). This one adds a DC-DC buck-boost converter and a supercapacitor bank to recover energy when the robot decelerates.

Your Hardware Used: DC motors, motor driver (H-bridge), IR sensors, microcontroller, and a 2S Li-ion battery pack.

The "EEE Twist" You Add: You design a small secondary PCB that includes a supercapacitor charging circuit and a buck-boost converter. When the robot detects a sharp turn (via IR sensors) and slows down, the back-EMF from the motors is rectified and dumped into the supercapacitor instead of wasting it as heat in the H-bridge.

Student Deliverables:

Calculate the capacitance needed to store braking energy for 3 seconds.

Design the switching converter topology (buck-boost) to discharge the supercap back to the drive motors during acceleration.

Tune the PID while monitoring battery current draw on an oscilloscope.

Learning Outcomes: Back-EMF, synchronous rectification, power efficiency (≥85%), capacitor sizing, and current sensing.

Project 2: "Wireless Power Transfer (WPT) Charging Bot" (Analog & High-Frequency Focus)
Why this sells: EEE students rarely get to play with high-frequency AC. This project removes all charging ports. The robot charges wirelessly via inductive coupling.

Your Hardware Used: The robot chassis, motors, and microcontroller.

The "EEE Twist" You Add: You design two coils (Transmitter pad on the floor, Receiver coil under the robot). The student must build the Class-E power amplifier (using MOSFETs) on the transmitter side to drive the coil at 100-200 kHz, and build the full-bridge rectifier + smoothing filter + battery charging IC on the robot side.

Student Deliverables:

Tune the resonant frequency of the LC tank circuit to match the driver frequency.

Measure the AC-to-DC conversion efficiency at varying distances (1cm to 5cm).

Design the over-voltage protection circuit to prevent frying the Li-ion battery when the robot is perfectly aligned over the pad.

Learning Outcomes: Resonance, MOSFET switching losses, high-frequency AC measurement, rectifier ripple, and magnetic coupling coefficient (k).

Project 3: "3-Phase BLDC Motor Drive for a Differential Bot" (Motor Control Focus)
Why this sells: Brushed DC motors are "EEE 101". Recruiters are desperate for students who know Field-Oriented Control (FOC) for BLDC motors used in EVs and drones.

Your Hardware Used: Keep your chassis and microcontroller, but swap your two brushed DC motors for two small gimbal BLDC motors with quadrature encoders.

The "EEE Twist" You Add: You provide the 3-phase inverter (6 MOSFET H-bridge) and gate driver ICs. The student does not get to use a pre-made ESC (Electronic Speed Controller). They must write the firmware to generate the 6 complementary PWM signals with dead-time insertion.

Student Deliverables:

Implement Trapezoidal (Six-step) commutation using Hall sensors (or encoder feedback).

Measure the dead-time to prevent shoot-through current.

Implement closed-loop speed control for both wheels independently so the robot drives straight.

Learning Outcomes: 3-phase PWM generation, dead-time calculation, MOSFET gate charge requirements, back-EMF zero-crossing detection, and torque ripple analysis.

Packaging Advice for You
Since these are for undergraduates, do not sell them a bare PCB and a bag of components. Professors hate that because half the students will burn out their MOSFETs and give up.

Package it as a "Hardware Interface Board":

The Main Robot Base (your existing design).

The "Expansion Module" (this is the specific EEE circuit for the project above—e.g., the WPT coil driver, or the BLDC power stage).

A sacrificial component pack (extra MOSFETs, diodes, and fuses) because you know they will short something out.

A 100-page Lab Manual with oscilloscope probe points clearly marked on the PCB.

Project 2: The Grid Navigator (A* & Line Follower Hybrid)
This is a lower-cost, more accessible alternative to the physical maze. The robot navigates a grid using a line-following base but is tasked with deciding which path to take to reach a target, adding a layer of intelligence.

Hardware Concept: Use your existing hardware with an array of IR line sensors to detect lines on the floor, along with additional sensors (or the same ones) to detect intersections or obstacles . This is a less mechanically demanding project than the maze solver.

The "EEE Twist": Students program the robot to not just follow a line, but to plan its route at intersections. They implement the A* pathfinding algorithm, which is a fundamental concept in AI and robotics, to find the optimal path to a set destination on the grid . This involves translating a 2D grid map into a digital format the robot can understand, possibly via a web interface or pre-loaded map .

Student Deliverables:

Program the robot to identify different types of intersections (T-junction, 4-way, etc.).

Implement an A* pathfinding algorithm to choose the correct path from a known grid map.

Learning Outcomes: Pathfinding algorithms (A*), finite state machines, sensor fusion, and data structure manipulation in C/C++ .

Project 3: The Reactive Navigator (RRT/ Obstacle Avoidance)
This project is ideal if you want to focus more on hardware integration and real-time response than on mapping. The robot doesn't know the environment; it explores and reacts using its sensors.

Hardware Concept: Use your robot equipped with an ultrasonic sensor for distance measurement and a servo to sweep it for a wider field of view . This creates a simple "scanning" system.

The "EEE Twist": Students implement a simple reactive algorithm where the robot explores an unknown space. They can implement the RRT (Rapidly-exploring Random Tree) algorithm, which is a powerful sampling-based planner . A simpler version could be a "wall follower" algorithm that turns right when it hits a wall .

Student Deliverables:

Learning Outcomes: Motor control, sensor scanning techniques, obstacle avoidance algorithms, and the implementation of a sampling-based planning strategy.

How It Works (The 30-Second Pitch)

Algorithm Implementation: Writing a Python script to process the raw data, build a 2D occupancy grid map, and potentially implement a simple frontier-exploration algorithm to make the robot explore autonomously.

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from nav_msgs.msg import OccupancyGrid, Path, Odometry
from geometry_msgs.msg import PoseStamped, Point, PoseWithCovarianceStamped
from visualization_msgs.msg import Marker, MarkerArray
import numpy as np
import heapq
from collections import deque
import time
import math

class SwarmPathfinder(Node):
    def __init__(self):
        super().__init__('swarm_pathfinder')
        
        # Subscribers
        self.map_sub = self.create_subscription(
            OccupancyGrid, '/map', self.map_callback, 10)
        self.goal_sub = self.create_subscription(
            PoseStamped, '/goal_pose', self.goal_callback, 10)
        self.odom_sub = self.create_subscription(
            Odometry, '/odom', self.odom_callback, 10)
        
        # Publishers
        self.path_pub = self.create_publisher(Path, '/planned_path', 10)
        self.marker_pub = self.create_publisher(
            MarkerArray, '/path_markers', 10)
        self.explored_pub = self.create_publisher(
            Marker, '/explored_nodes', 10)
        
        # Variables
        self.map_data = None
        self.map_info = None
        self.robot_pose = None
        self.goal_pose = None
        self.current_path = None
        
        # Algorithm selection
        self.algorithms = {
            'astar': self.astar_search,
            'dijkstra': self.dijkstra_search,
            'bfs': self.bfs_search,
            'greedy_bfs': self.greedy_bfs_search,
            'bidirectional_astar': self.bidirectional_astar_search
        }
        
        # Declare ROS parameter for algorithm selection
        self.declare_parameter('algorithm', 'astar')
        self.declare_parameter('allow_unknown', False)
        self.declare_parameter('safety_distance', 1)  # cells
        
        # Timer for continuous planning
        self.timer = self.create_timer(0.5, self.planning_loop)
        
        # Stats
        self.planning_stats = {
            'nodes_explored': 0,
            'path_length': 0,
            'time_ms': 0
        }
        
        self.get_logger().info('🚀 Swarm Pathfinder Ready on Linux!')
        
    def map_callback(self, msg):
        """Process occupancy grid map"""
        self.map_info = msg.info
        width = msg.info.width
        height = msg.info.height
        
        # Convert to numpy array
        grid_data = np.array(msg.data, dtype=np.int8).reshape((height, width))
        
        # Convert to: 0=free, 1=obstacle, -1=unknown
        self.map_data = np.where(grid_data == 100, 1, 
                       np.where(grid_data == 0, 0, -1))
        
        self.get_logger().debug(
            f'Map received: {width}x{height}, '
            f'Resolution: {msg.info.resolution}m'
        )
        
    def odom_callback(self, msg):
        """Track robot position"""
        self.robot_pose = msg.pose.pose
        
    def goal_callback(self, msg):
        """Receive navigation goal"""
        self.goal_pose = msg.pose
        self.get_logger().info(
            f'🎯 New goal: ({msg.pose.position.x:.2f}, '
            f'{msg.pose.position.y:.2f})'
        )
        
    def world_to_grid(self, wx, wy):
        """World coordinates to grid coordinates"""
        if self.map_info is None:
            return None
        
        gx = int((wx - self.map_info.origin.position.x) / 
                 self.map_info.resolution)
        gy = int((wy - self.map_info.origin.position.y) / 
                 self.map_info.resolution)
        
        # Check bounds
        if (0 <= gx < self.map_info.width and 
            0 <= gy < self.map_info.height):
            return (gx, gy)
        return None
    
    def grid_to_world(self, gx, gy):
        """Grid coordinates to world coordinates"""
        if self.map_info is None:
            return (0.0, 0.0)
        
        wx = gx * self.map_info.resolution + self.map_info.origin.position.x
        wy = gy * self.map_info.resolution + self.map_info.origin.position.y
        return (wx, wy)
    
    def planning_loop(self):
        """Main planning cycle"""
        if (self.map_data is None or 
            self.robot_pose is None or 
            self.goal_pose is None):
            return
        
        # Get current algorithm from parameter
        algo_name = self.get_parameter('algorithm').value
        
        # Convert positions to grid
        start = self.world_to_grid(
            self.robot_pose.position.x,
            self.robot_pose.position.y
        )
        goal = self.world_to_grid(
            self.goal_pose.position.x,
            self.goal_pose.position.y
        )
        
        if start is None or goal is None:
            self.get_logger().warn('Start or goal out of map bounds!')
            return
        
        # Find path using selected algorithm
        if algo_name in self.algorithms:
            start_time = time.time()
            path = self.algorithms[algo_name](start, goal)
            elapsed = (time.time() - start_time) * 1000
            
            if path:
                self.planning_stats['time_ms'] = elapsed
                self.planning_stats['path_length'] = len(path)
                
                # Publish path
                self.publish_path(path)
                self.publish_markers(path)
                
                self.get_logger().info(
                    f'✅ Path found: {len(path)} waypoints '
                    f'({elapsed:.1f}ms) using {algo_name}'
                )
            else:
                self.get_logger().warn(
                    f'❌ No path found using {algo_name}'
                )
    
    def astar_search(self, start, goal):
        """A* algorithm adapted for ROS occupancy grid"""
        if self.map_data is None:
            return None
        
        height, width = self.map_data.shape
        allow_unknown = self.get_parameter('allow_unknown').value
        safety_dist = self.get_parameter('safety_distance').value
        
        def is_free(x, y):
            """Check if cell is free (with safety margin)"""
            if not (0 <= x < width and 0 <= y < height):
                return False
            
            cell = self.map_data[y, x]
            if cell == 1:  # Occupied
                return False
            if cell == -1 and not allow_unknown:  # Unknown
                return False
            
            # Safety margin check
            if safety_dist > 0:
                for dx in range(-safety_dist, safety_dist + 1):
                    for dy in range(-safety_dist, safety_dist + 1):
                        nx, ny = x + dx, y + dy
                        if (0 <= nx < width and 0 <= ny < height):
                            if self.map_data[ny, nx] == 1:
                                return False
            return True
        
        def heuristic(a, b):
            return math.sqrt((a[0]-b[0])**2 + (a[1]-b[1])**2)
        
        open_set = [(0, 0, start)]  # (f_score, tiebreaker, position)
        came_from = {}
        g_score = {start: 0}
        open_hash = {start}
        tiebreaker = 0
        
        self.planning_stats['nodes_explored'] = 0
        
        while open_set:
            _, _, current = heapq.heappop(open_set)
            open_hash.remove(current)
            self.planning_stats['nodes_explored'] += 1
            
            if current == goal:
                # Reconstruct path
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                
                if not is_free(nx, ny):
                    continue
                
                neighbor = (nx, ny)
                tentative_g = g_score[current] + 1
                
                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g
                    f = tentative_g + heuristic(neighbor, goal)
                    tiebreaker += 1
                    heapq.heappush(open_set, (f, tiebreaker, neighbor))
                    open_hash.add(neighbor)
        
        return None
    
    def dijkstra_search(self, start, goal):
        """Dijkstra's algorithm"""
        # Similar to A* but without heuristic
        if self.map_data is None:
            return None
        
        height, width = self.map_data.shape
        
        def is_free(x, y):
            if not (0 <= x < width and 0 <= y < height):
                return False
            return self.map_data[y, x] != 1
        
        open_set = [(0, start)]
        came_from = {}
        g_score = {start: 0}
        
        while open_set:
            current_g, current = heapq.heappop(open_set)
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                
                if not is_free(nx, ny):
                    continue
                
                neighbor = (nx, ny)
                tentative_g = g_score[current] + 1
                
                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g
                    heapq.heappush(open_set, (tentative_g, neighbor))
        
        return None
    
    def bfs_search(self, start, goal):
        """Breadth-First Search"""
        if self.map_data is None:
            return None
        
        height, width = self.map_data.shape
        
        def is_free(x, y):
            if not (0 <= x < width and 0 <= y < height):
                return False
            return self.map_data[y, x] != 1
        
        queue = deque([start])
        came_from = {}
        visited = {start}
        
        while queue:
            current = queue.popleft()
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                
                if not is_free(nx, ny):
                    continue
                
                neighbor = (nx, ny)
                if neighbor not in visited:
                    visited.add(neighbor)
                    came_from[neighbor] = current
                    queue.append(neighbor)
        
        return None
    
    def greedy_bfs_search(self, start, goal):
        """Greedy Best-First Search"""
        if self.map_data is None:
            return None
        
        height, width = self.map_data.shape
        
        def is_free(x, y):
            if not (0 <= x < width and 0 <= y < height):
                return False
            return self.map_data[y, x] != 1
        
        def heuristic(a, b):
            return abs(a[0]-b[0]) + abs(a[1]-b[1])
        
        open_set = [(heuristic(start, goal), start)]
        came_from = {}
        visited = {start}
        
        while open_set:
            _, current = heapq.heappop(open_set)
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                
                if not is_free(nx, ny):
                    continue
                
                neighbor = (nx, ny)
                if neighbor not in visited:
                    visited.add(neighbor)
                    came_from[neighbor] = current
                    heapq.heappush(open_set, 
                                 (heuristic(neighbor, goal), neighbor))
        
        return None
    
    def bidirectional_astar_search(self, start, goal):
        """Bidirectional A* Search"""
        if self.map_data is None:
            return None
        
        height, width = self.map_data.shape
        
        def is_free(x, y):
            if not (0 <= x < width and 0 <= y < height):
                return False
            return self.map_data[y, x] != 1
        
        def heuristic(a, b):
            return abs(a[0]-b[0]) + abs(a[1]-b[1])
        
        # Forward search
        fwd_open = [(0, start)]
        fwd_g = {start: 0}
        fwd_parent = {}
        fwd_closed = set()
        
        # Backward search
        bwd_open = [(0, goal)]
        bwd_g = {goal: 0}
        bwd_parent = {}
        bwd_closed = set()
        
        while fwd_open and bwd_open:
            # Expand forward
            if fwd_open:
                _, current = heapq.heappop(fwd_open)
                fwd_closed.add(current)
                
                if current in bwd_closed:
                    # Path found! Merge forward and backward
                    path = []
                    # Forward path
                    node = current
                    while node in fwd_parent:
                        path.append(node)
                        node = fwd_parent[node]
                    path.append(start)
                    path.reverse()
                    # Backward path
                    node = current
                    while node in bwd_parent:
                        node = bwd_parent[node]
                        path.append(node)
                    return path
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = current[0] + dx, current[1] + dy
                    
                    if not is_free(nx, ny):
                        continue
                    
                    neighbor = (nx, ny)
                    tentative_g = fwd_g[current] + 1
                    
                    if neighbor not in fwd_g or tentative_g < fwd_g[neighbor]:
                        fwd_parent[neighbor] = current
                        fwd_g[neighbor] = tentative_g
                        f = tentative_g + heuristic(neighbor, goal)
                        heapq.heappush(fwd_open, (f, neighbor))
            
            # Expand backward
            if bwd_open:
                _, current = heapq.heappop(bwd_open)
                bwd_closed.add(current)
                
                if current in fwd_closed:
                    # Path found! Merge
                    path = []
                    node = current
                    while node in fwd_parent:
                        path.append(node)
                        node = fwd_parent[node]
                    path.append(start)
                    path.reverse()
                    node = current
                    while node in bwd_parent:
                        node = bwd_parent[node]
                        path.append(node)
                    return path
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = current[0] + dx, current[1] + dy
                    
                    if not is_free(nx, ny):
                        continue
                    
                    neighbor = (nx, ny)
                    tentative_g = bwd_g[current] + 1
                    
                    if neighbor not in bwd_g or tentative_g < bwd_g[neighbor]:
                        bwd_parent[neighbor] = current
                        bwd_g[neighbor] = tentative_g
                        f = tentative_g + heuristic(neighbor, start)
                        heapq.heappush(bwd_open, (f, neighbor))
        
        return None
    
    def publish_path(self, grid_path):
        """Convert grid path to ROS Path message"""
        path_msg = Path()
        path_msg.header.frame_id = 'map'
        path_msg.header.stamp = self.get_clock().now().to_msg()
        
        for gx, gy in grid_path:
            wx, wy = self.grid_to_world(gx, gy)
            
            pose = PoseStamped()
            pose.header = path_msg.header
            pose.pose.position.x = wx
            pose.pose.position.y = wy
            pose.pose.orientation.w = 1.0
            
            path_msg.poses.append(pose)
        
        self.path_pub.publish(path_msg)
    
    def publish_markers(self, grid_path):
        """Publish visualization markers for RViz"""
        marker_array = MarkerArray()
        
        # Path line strip
        line_marker = Marker()
        line_marker.header.frame_id = 'map'
        line_marker.header.stamp = self.get_clock().now().to_msg()
        line_marker.ns = 'path'
        line_marker.id = 0
        line_marker.type = Marker.LINE_STRIP
        line_marker.action = Marker.ADD
        line_marker.scale.x = 0.05
        line_marker.color.a = 1.0
        line_marker.color.r = 0.0
        line_marker.color.g = 0.5
        line_marker.color.b = 1.0
        
        for gx, gy in grid_path:
            wx, wy = self.grid_to_world(gx, gy)
            p = Point(x=wx, y=wy, z=0.1)
            line_marker.points.append(p)
        
        marker_array.markers.append(line_marker)
        self.marker_pub.publish(marker_array)


def main(args=None):
    rclpy.init(args=args)
    node = SwarmPathfinder()
    
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        node.get_logger().info('Shutting down...')
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

#!/usr/bin/env python3
"""
Swarm Robotics Pathfinder Node for ROS 2
Integrates A*, Dijkstra, BFS, Greedy BFS, and Bidirectional A*
"""

import rclpy
from rclpy.node import Node
from nav_msgs.msg import OccupancyGrid, Path, Odometry
from geometry_msgs.msg import PoseStamped, Point
from visualization_msgs.msg import Marker, MarkerArray
from std_msgs.msg import String
import numpy as np
import heapq
from collections import deque
import time
import math

class SwarmPathfinder(Node):
    def __init__(self):
        super().__init__('swarm_pathfinder')
        
        # Subscribers
        self.map_sub = self.create_subscription(
            OccupancyGrid, '/map', self.map_callback, 10)
        self.goal_sub = self.create_subscription(
            PoseStamped, '/goal_pose', self.goal_callback, 10)
        self.odom_sub = self.create_subscription(
            Odometry, '/odom', self.odom_callback, 10)
        
        # Publishers
        self.path_pub = self.create_publisher(Path, '/planned_path', 10)
        self.marker_pub = self.create_publisher(MarkerArray, '/path_markers', 10)
        self.stats_pub = self.create_publisher(String, '/planner_stats', 10)
        
        # Parameters
        self.declare_parameter('algorithm', 'astar')
        self.declare_parameter('allow_unknown', False)
        self.declare_parameter('safety_distance', 1)
        self.declare_parameter('planning_frequency', 2.0)
        
        # State
        self.map_data = None
        self.map_info = None
        self.robot_pose = None
        self.goal_pose = None
        
        # Algorithm dictionary
        self.algorithms = {
            'astar': self.astar_search,
            'dijkstra': self.dijkstra_search,
            'bfs': self.bfs_search,
            'greedy_bfs': self.greedy_bfs_search,
            'bidirectional_astar': self.bidirectional_astar_search
        }
        
        # Stats tracking
        self.stats = {
            'nodes_explored': 0,
            'path_length': 0,
            'time_ms': 0.0
        }
        
        # Planning timer
        freq = self.get_parameter('planning_frequency').value
        self.timer = self.create_timer(1.0/freq, self.planning_loop)
        
        self.get_logger().info('🚀 Swarm Pathfinder Node Ready!')
        self.get_logger().info('📊 Available algorithms: ' + ', '.join(self.algorithms.keys()))
        
    def map_callback(self, msg):
        """Process incoming map"""
        self.map_info = msg.info
        width = msg.info.width
        height = msg.info.height
        grid_data = np.array(msg.data, dtype=np.int8).reshape((height, width))
        
        # Convert: 0=free, 100=occupied, -1=unknown
        self.map_data = np.where(grid_data == 100, 1, 
                       np.where(grid_data == 0, 0, -1))
        
    def odom_callback(self, msg):
        """Track robot position"""
        self.robot_pose = msg.pose.pose
        
    def goal_callback(self, msg):
        """Receive new goal"""
        self.goal_pose = msg.pose
        self.get_logger().info(
            f'🎯 New Goal: ({msg.pose.position.x:.2f}, {msg.pose.position.y:.2f})'
        )
        
    def world_to_grid(self, wx, wy):
        """Convert world to grid coordinates"""
        if self.map_info is None:
            return None
        gx = int((wx - self.map_info.origin.position.x) / self.map_info.resolution)
        gy = int((wy - self.map_info.origin.position.y) / self.map_info.resolution)
        if 0 <= gx < self.map_info.width and 0 <= gy < self.map_info.height:
            return (gx, gy)
        return None
        
    def grid_to_world(self, gx, gy):
        """Convert grid to world coordinates"""
        if self.map_info is None:
            return (0.0, 0.0)
        wx = gx * self.map_info.resolution + self.map_info.origin.position.x
        wy = gy * self.map_info.resolution + self.map_info.origin.position.y
        return (wx, wy)
        
    def is_cell_free(self, x, y):
        """Check if cell is free considering safety margin"""
        if self.map_data is None:
            return False
        height, width = self.map_data.shape
        if not (0 <= x < width and 0 <= y < height):
            return False
        
        allow_unknown = self.get_parameter('allow_unknown').value
        safety_dist = self.get_parameter('safety_distance').value
        
        cell = self.map_data[y, x]
        if cell == 1:
            return False
        if cell == -1 and not allow_unknown:
            return False
            
        # Safety margin check
        if safety_dist > 0:
            for dx in range(-safety_dist, safety_dist + 1):
                for dy in range(-safety_dist, safety_dist + 1):
                    nx, ny = x + dx, y + dy
                    if (0 <= nx < width and 0 <= ny < height):
                        if self.map_data[ny, nx] == 1:
                            return False
        return True
        
    def planning_loop(self):
        """Main planning loop"""
        if self.map_data is None or self.robot_pose is None or self.goal_pose is None:
            return
            
        algo_name = self.get_parameter('algorithm').value
        
        start = self.world_to_grid(
            self.robot_pose.position.x,
            self.robot_pose.position.y
        )
        goal = self.world_to_grid(
            self.goal_pose.position.x,
            self.goal_pose.position.y
        )
        
        if start is None or goal is None:
            self.get_logger().warn('Start or goal out of bounds!')
            return
            
        if algo_name in self.algorithms:
            start_time = time.time()
            path = self.algorithms[algo_name](start, goal)
            elapsed = (time.time() - start_time) * 1000
            
            if path:
                self.stats['time_ms'] = elapsed
                self.stats['path_length'] = len(path)
                self.publish_path(path)
                self.publish_markers(path)
                self.publish_stats(algo_name)
                
                self.get_logger().info(
                    f'✅ [{algo_name}] Path: {len(path)}pts, '
                    f'Time: {elapsed:.1f}ms, '
                    f'Nodes: {self.stats["nodes_explored"]}'
                )
            else:
                self.get_logger().warn(f'❌ [{algo_name}] No path found!')
                
    def astar_search(self, start, goal):
        """A* Algorithm"""
        if self.map_data is None:
            return None
            
        def heuristic(a, b):
            return math.sqrt((a[0]-b[0])**2 + (a[1]-b[1])**2)
        
        open_set = [(0, 0, start)]
        came_from = {}
        g_score = {start: 0}
        open_hash = {start}
        tiebreaker = 0
        self.stats['nodes_explored'] = 0
        
        while open_set:
            _, _, current = heapq.heappop(open_set)
            open_hash.remove(current)
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                tentative_g = g_score[current] + 1
                
                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g
                    f = tentative_g + heuristic(neighbor, goal)
                    tiebreaker += 1
                    heapq.heappush(open_set, (f, tiebreaker, neighbor))
                    open_hash.add(neighbor)
        return None
        
    def dijkstra_search(self, start, goal):
        """Dijkstra's Algorithm"""
        open_set = [(0, start)]
        came_from = {}
        g_score = {start: 0}
        self.stats['nodes_explored'] = 0
        
        while open_set:
            current_g, current = heapq.heappop(open_set)
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                tentative_g = g_score[current] + 1
                
                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g
                    heapq.heappush(open_set, (tentative_g, neighbor))
        return None
        
    def bfs_search(self, start, goal):
        """Breadth-First Search"""
        queue = deque([start])
        came_from = {}
        visited = {start}
        self.stats['nodes_explored'] = 0
        
        while queue:
            current = queue.popleft()
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                if neighbor not in visited:
                    visited.add(neighbor)
                    came_from[neighbor] = current
                    queue.append(neighbor)
        return None
        
    def greedy_bfs_search(self, start, goal):
        """Greedy Best-First Search"""
        def heuristic(a, b):
            return abs(a[0]-b[0]) + abs(a[1]-b[1])
            
        open_set = [(heuristic(start, goal), start)]
        came_from = {}
        visited = {start}
        self.stats['nodes_explored'] = 0
        
        while open_set:
            _, current = heapq.heappop(open_set)
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                if neighbor not in visited:
                    visited.add(neighbor)
                    came_from[neighbor] = current
                    heapq.heappush(open_set, (heuristic(neighbor, goal), neighbor))
        return None
        
    def bidirectional_astar_search(self, start, goal):
        """Bidirectional A* Search"""
        def heuristic(a, b):
            return abs(a[0]-b[0]) + abs(a[1]-b[1])
            
        fwd_open = [(0, start)]
        fwd_g = {start: 0}
        fwd_parent = {}
        fwd_closed = set()
        
        bwd_open = [(0, goal)]
        bwd_g = {goal: 0}
        bwd_parent = {}
        bwd_closed = set()
        
        self.stats['nodes_explored'] = 0
        
        while fwd_open and bwd_open:
            if fwd_open:
                _, current = heapq.heappop(fwd_open)
                fwd_closed.add(current)
                self.stats['nodes_explored'] += 1
                
                if current in bwd_closed:
                    path = []
                    node = current
                    while node in fwd_parent:
                        path.append(node)
                        node = fwd_parent[node]
                    path.append(start)
                    path.reverse()
                    node = current
                    while node in bwd_parent:
                        node = bwd_parent[node]
                        path.append(node)
                    return path
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = current[0] + dx, current[1] + dy
                    if not self.is_cell_free(nx, ny):
                        continue
                    neighbor = (nx, ny)
                    tentative_g = fwd_g[current] + 1
                    if neighbor not in fwd_g or tentative_g < fwd_g[neighbor]:
                        fwd_parent[neighbor] = current
                        fwd_g[neighbor] = tentative_g
                        f = tentative_g + heuristic(neighbor, goal)
                        heapq.heappush(fwd_open, (f, neighbor))
            
            if bwd_open:
                _, current = heapq.heappop(bwd_open)
                bwd_closed.add(current)
                self.stats['nodes_explored'] += 1
                
                if current in fwd_closed:
                    path = []
                    node = current
                    while node in fwd_parent:
                        path.append(node)
                        node = fwd_parent[node]
                    path.append(start)
                    path.reverse()
                    node = current
                    while node in bwd_parent:
                        node = bwd_parent[node]
                        path.append(node)
                    return path
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = current[0] + dx, current[1] + dy
                    if not self.is_cell_free(nx, ny):
                        continue
                    neighbor = (nx, ny)
                    tentative_g = bwd_g[current] + 1
                    if neighbor not in bwd_g or tentative_g < bwd_g[neighbor]:
                        bwd_parent[neighbor] = current
                        bwd_g[neighbor] = tentative_g
                        f = tentative_g + heuristic(neighbor, start)
                        heapq.heappush(bwd_open, (f, neighbor))
        return None
        
    def publish_path(self, grid_path):
        """Publish path as ROS message"""
        path_msg = Path()
        path_msg.header.frame_id = 'map'
        path_msg.header.stamp = self.get_clock().now().to_msg()
        
        for gx, gy in grid_path:
            wx, wy = self.grid_to_world(gx, gy)
            pose = PoseStamped()
            pose.header = path_msg.header
            pose.pose.position.x = wx
            pose.pose.position.y = wy
            pose.pose.orientation.w = 1.0
            path_msg.poses.append(pose)
            
        self.path_pub.publish(path_msg)
        
    def publish_markers(self, grid_path):
        """Publish visualization markers"""
        marker_array = MarkerArray()
        
        marker = Marker()
        marker.header.frame_id = 'map'
        marker.header.stamp = self.get_clock().now().to_msg()
        marker.ns = 'path'
        marker.id = 0
        marker.type = Marker.LINE_STRIP
        marker.action = Marker.ADD
        marker.scale.x = 0.03
        marker.color.a = 1.0
        marker.color.b = 1.0
        
        for gx, gy in grid_path:
            wx, wy = self.grid_to_world(gx, gy)
            marker.points.append(Point(x=wx, y=wy, z=0.05))
            
        marker_array.markers.append(marker)
        self.marker_pub.publish(marker_array)
        
    def publish_stats(self, algo_name):
        """Publish planning statistics"""
        stats_msg = String()
        stats_msg.data = (
            f"Algorithm: {algo_name}\n"
            f"Path Length: {self.stats['path_length']} cells\n"
            f"Nodes Explored: {self.stats['nodes_explored']}\n"
            f"Time: {self.stats['time_ms']:.2f} ms"
        )
        self.stats_pub.publish(stats_msg)

def main(args=None):
    rclpy.init(args=args)
    node = SwarmPathfinder()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

#!/usr/bin/env python3
"""Node to easily switch between algorithms"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String
import sys

class AlgorithmSwitcher(Node):
    def __init__(self):
        super().__init__('algorithm_switcher')
        self.param_client = self.create_client(
            SetParameters, '/swarm_pathfinder/set_parameters')
        
        self.get_logger().info('Algorithm Switcher Ready!')
        self.get_logger().info('Usage: ros2 run swarm_pathfinder algorithm_switcher <algorithm>')
        
    def switch_algorithm(self, algo_name):
        """Switch the pathfinding algorithm"""
        algorithms = ['astar', 'dijkstra', 'bfs', 'greedy_bfs', 'bidirectional_astar']
        
        if algo_name not in algorithms:
            self.get_logger().error(f'Unknown algorithm: {algo_name}')
            self.get_logger().info(f'Available: {algorithms}')
            return
            
        # Set parameter
        from rclpy.parameter import Parameter
        param = Parameter('algorithm', value=algo_name)
        
        self.get_logger().info(f'Switching to: {algo_name}')

def main(args=None):
    rclpy.init(args=args)
    
    if len(sys.argv) > 1:
        algo = sys.argv[1]
        # Use ros2 param set instead
        import os
        os.system(f'ros2 param set /swarm_pathfinder algorithm {algo}')
        print(f'✅ Switched to {algo}')
    else:
        print('Available algorithms:')
        print('  - astar')
        print('  - dijkstra')
        print('  - bfs')
        print('  - greedy_bfs')
        print('  - bidirectional_astar')
        print('\nUsage: ros2 run swarm_pathfinder algorithm_switcher <algorithm>')
    
    rclpy.shutdown()

if __name__ == '__main__':
    main()
EOF

#!/usr/bin/env python3
"""
Swarm Robotics Pathfinder Node for ROS 2
Integrates A*, Dijkstra, BFS, Greedy BFS, and Bidirectional A*
"""

import rclpy
from rclpy.node import Node
from nav_msgs.msg import OccupancyGrid, Path, Odometry
from geometry_msgs.msg import PoseStamped, Point
from visualization_msgs.msg import Marker, MarkerArray
from std_msgs.msg import String
import numpy as np
import heapq
from collections import deque
import time
import math

class SwarmPathfinder(Node):
    def __init__(self):
        super().__init__('swarm_pathfinder')
        
        # Subscribers
        self.map_sub = self.create_subscription(
            OccupancyGrid, '/map', self.map_callback, 10)
        self.goal_sub = self.create_subscription(
            PoseStamped, '/goal_pose', self.goal_callback, 10)
        self.odom_sub = self.create_subscription(
            Odometry, '/odom', self.odom_callback, 10)
        
        # Publishers
        self.path_pub = self.create_publisher(Path, '/planned_path', 10)
        self.marker_pub = self.create_publisher(MarkerArray, '/path_markers', 10)
        self.stats_pub = self.create_publisher(String, '/planner_stats', 10)
        
        # Parameters
        self.declare_parameter('algorithm', 'astar')
        self.declare_parameter('allow_unknown', False)
        self.declare_parameter('safety_distance', 1)
        self.declare_parameter('planning_frequency', 2.0)
        
        # State
        self.map_data = None
        self.map_info = None
        self.robot_pose = None
        self.goal_pose = None
        
        # Algorithm dictionary
        self.algorithms = {
            'astar': self.astar_search,
            'dijkstra': self.dijkstra_search,
            'bfs': self.bfs_search,
            'greedy_bfs': self.greedy_bfs_search,
            'bidirectional_astar': self.bidirectional_astar_search
        }
        
        # Stats tracking
        self.stats = {
            'nodes_explored': 0,
            'path_length': 0,
            'time_ms': 0.0
        }
        
        # Planning timer
        freq = self.get_parameter('planning_frequency').value
        self.timer = self.create_timer(1.0/freq, self.planning_loop)
        
        self.get_logger().info('🚀 Swarm Pathfinder Node Ready!')
        self.get_logger().info('📊 Available algorithms: ' + ', '.join(self.algorithms.keys()))
        
    def map_callback(self, msg):
        """Process incoming map with validation"""
        try:
            self.map_info = msg.info
            width = msg.info.width
            height = msg.info.height
            
            # Validate map dimensions
            expected_size = width * height
            actual_size = len(msg.data)
            
            if expected_size != actual_size:
                self.get_logger().warn(
                    f'Map size mismatch! Expected {expected_size} cells '
                    f'({width}x{height}), got {actual_size}. Ignoring map.'
                )
                return
            
            grid_data = np.array(msg.data, dtype=np.int8).reshape((height, width))
            
            # Convert: 0=free, 100=occupied, -1=unknown
            self.map_data = np.where(grid_data == 100, 1, 
                           np.where(grid_data == 0, 0, -1))
            
            obstacle_count = (self.map_data == 1).sum()
            self.get_logger().info(
                f'Map updated: {width}x{height}, {obstacle_count} obstacles'
            )
            
        except Exception as e:
            self.get_logger().error(f'Error processing map: {e}')
        
    def odom_callback(self, msg):
        """Track robot position"""
        self.robot_pose = msg.pose.pose
        
    def goal_callback(self, msg):
        """Receive new goal"""
        self.goal_pose = msg.pose
        self.get_logger().info(
            f'🎯 New Goal: ({msg.pose.position.x:.2f}, {msg.pose.position.y:.2f})'
        )
        
    def world_to_grid(self, wx, wy):
        """Convert world to grid coordinates"""
        if self.map_info is None:
            return None
        gx = int((wx - self.map_info.origin.position.x) / self.map_info.resolution)
        gy = int((wy - self.map_info.origin.position.y) / self.map_info.resolution)
        if 0 <= gx < self.map_info.width and 0 <= gy < self.map_info.height:
            return (gx, gy)
        return None
        
    def grid_to_world(self, gx, gy):
        """Convert grid to world coordinates"""
        if self.map_info is None:
            return (0.0, 0.0)
        wx = gx * self.map_info.resolution + self.map_info.origin.position.x
        wy = gy * self.map_info.resolution + self.map_info.origin.position.y
        return (wx, wy)
        
    def is_cell_free(self, x, y):
        """Check if cell is free considering safety margin"""
        if self.map_data is None:
            return False
        height, width = self.map_data.shape
        if not (0 <= x < width and 0 <= y < height):
            return False
        
        allow_unknown = self.get_parameter('allow_unknown').value
        safety_dist = self.get_parameter('safety_distance').value
        
        cell = self.map_data[y, x]
        if cell == 1:
            return False
        if cell == -1 and not allow_unknown:
            return False
            
        # Safety margin check
        if safety_dist > 0:
            for dx in range(-safety_dist, safety_dist + 1):
                for dy in range(-safety_dist, safety_dist + 1):
                    nx, ny = x + dx, y + dy
                    if (0 <= nx < width and 0 <= ny < height):
                        if self.map_data[ny, nx] == 1:
                            return False
        return True
        
    def planning_loop(self):
        """Main planning loop"""
        if self.map_data is None or self.robot_pose is None or self.goal_pose is None:
            return
            
        algo_name = self.get_parameter('algorithm').value
        
        start = self.world_to_grid(
            self.robot_pose.position.x,
            self.robot_pose.position.y
        )
        goal = self.world_to_grid(
            self.goal_pose.position.x,
            self.goal_pose.position.y
        )
        
        if start is None or goal is None:
            self.get_logger().warn('Start or goal out of bounds!')
            return
            
        if algo_name in self.algorithms:
            start_time = time.time()
            path = self.algorithms[algo_name](start, goal)
            elapsed = (time.time() - start_time) * 1000
            
            if path:
                self.stats['time_ms'] = elapsed
                self.stats['path_length'] = len(path)
                self.publish_path(path)
                self.publish_markers(path)
                self.publish_stats(algo_name)
                
                self.get_logger().info(
                    f'✅ [{algo_name}] Path: {len(path)}pts, '
                    f'Time: {elapsed:.1f}ms, '
                    f'Nodes: {self.stats["nodes_explored"]}'
                )
            else:
                self.get_logger().warn(f'❌ [{algo_name}] No path found!')
                
    def astar_search(self, start, goal):
        """A* Algorithm"""
        if self.map_data is None:
            return None
            
        def heuristic(a, b):
            return math.sqrt((a[0]-b[0])**2 + (a[1]-b[1])**2)
        
        open_set = [(0, 0, start)]
        came_from = {}
        g_score = {start: 0}
        open_hash = {start}
        tiebreaker = 0
        self.stats['nodes_explored'] = 0
        
        while open_set:
            _, _, current = heapq.heappop(open_set)
            open_hash.remove(current)
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                tentative_g = g_score[current] + 1
                
                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g
                    f = tentative_g + heuristic(neighbor, goal)
                    tiebreaker += 1
                    heapq.heappush(open_set, (f, tiebreaker, neighbor))
                    open_hash.add(neighbor)
        return None
        
    def dijkstra_search(self, start, goal):
        """Dijkstra's Algorithm"""
        open_set = [(0, start)]
        came_from = {}
        g_score = {start: 0}
        self.stats['nodes_explored'] = 0
        
        while open_set:
            current_g, current = heapq.heappop(open_set)
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                tentative_g = g_score[current] + 1
                
                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g
                    heapq.heappush(open_set, (tentative_g, neighbor))
        return None
        
    def bfs_search(self, start, goal):
        """Breadth-First Search"""
        queue = deque([start])
        came_from = {}
        visited = {start}
        self.stats['nodes_explored'] = 0
        
        while queue:
            current = queue.popleft()
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                if neighbor not in visited:
                    visited.add(neighbor)
                    came_from[neighbor] = current
                    queue.append(neighbor)
        return None
        
    def greedy_bfs_search(self, start, goal):
        """Greedy Best-First Search"""
        def heuristic(a, b):
            return abs(a[0]-b[0]) + abs(a[1]-b[1])
            
        open_set = [(heuristic(start, goal), start)]
        came_from = {}
        visited = {start}
        self.stats['nodes_explored'] = 0
        
        while open_set:
            _, current = heapq.heappop(open_set)
            self.stats['nodes_explored'] += 1
            
            if current == goal:
                path = []
                while current in came_from:
                    path.append(current)
                    current = came_from[current]
                path.append(start)
                return path[::-1]
            
            for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                nx, ny = current[0] + dx, current[1] + dy
                if not self.is_cell_free(nx, ny):
                    continue
                    
                neighbor = (nx, ny)
                if neighbor not in visited:
                    visited.add(neighbor)
                    came_from[neighbor] = current
                    heapq.heappush(open_set, (heuristic(neighbor, goal), neighbor))
        return None
        
    def bidirectional_astar_search(self, start, goal):
        """Bidirectional A* Search"""
        def heuristic(a, b):
            return abs(a[0]-b[0]) + abs(a[1]-b[1])
            
        fwd_open = [(0, start)]
        fwd_g = {start: 0}
        fwd_parent = {}
        fwd_closed = set()
        
        bwd_open = [(0, goal)]
        bwd_g = {goal: 0}
        bwd_parent = {}
        bwd_closed = set()
        
        self.stats['nodes_explored'] = 0
        
        while fwd_open and bwd_open:
            if fwd_open:
                _, current = heapq.heappop(fwd_open)
                fwd_closed.add(current)
                self.stats['nodes_explored'] += 1
                
                if current in bwd_closed:
                    path = []
                    node = current
                    while node in fwd_parent:
                        path.append(node)
                        node = fwd_parent[node]
                    path.append(start)
                    path.reverse()
                    node = current
                    while node in bwd_parent:
                        node = bwd_parent[node]
                        path.append(node)
                    return path
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = current[0] + dx, current[1] + dy
                    if not self.is_cell_free(nx, ny):
                        continue
                    neighbor = (nx, ny)
                    tentative_g = fwd_g[current] + 1
                    if neighbor not in fwd_g or tentative_g < fwd_g[neighbor]:
                        fwd_parent[neighbor] = current
                        fwd_g[neighbor] = tentative_g
                        f = tentative_g + heuristic(neighbor, goal)
                        heapq.heappush(fwd_open, (f, neighbor))
            
            if bwd_open:
                _, current = heapq.heappop(bwd_open)
                bwd_closed.add(current)
                self.stats['nodes_explored'] += 1
                
                if current in fwd_closed:
                    path = []
                    node = current
                    while node in fwd_parent:
                        path.append(node)
                        node = fwd_parent[node]
                    path.append(start)
                    path.reverse()
                    node = current
                    while node in bwd_parent:
                        node = bwd_parent[node]
                        path.append(node)
                    return path
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = current[0] + dx, current[1] + dy
                    if not self.is_cell_free(nx, ny):
                        continue
                    neighbor = (nx, ny)
                    tentative_g = bwd_g[current] + 1
                    if neighbor not in bwd_g or tentative_g < bwd_g[neighbor]:
                        bwd_parent[neighbor] = current
                        bwd_g[neighbor] = tentative_g
                        f = tentative_g + heuristic(neighbor, start)
                        heapq.heappush(bwd_open, (f, neighbor))
        return None
        
    def publish_path(self, grid_path):
        """Publish path as ROS message"""
        path_msg = Path()
        path_msg.header.frame_id = 'map'
        path_msg.header.stamp = self.get_clock().now().to_msg()
        
        for gx, gy in grid_path:
            wx, wy = self.grid_to_world(gx, gy)
            pose = PoseStamped()
            pose.header = path_msg.header
            pose.pose.position.x = wx
            pose.pose.position.y = wy
            pose.pose.orientation.w = 1.0
            path_msg.poses.append(pose)
            
        self.path_pub.publish(path_msg)
        
    def publish_markers(self, grid_path):
        """Publish visualization markers"""
        marker_array = MarkerArray()
        
        marker = Marker()
        marker.header.frame_id = 'map'
        marker.header.stamp = self.get_clock().now().to_msg()
        marker.ns = 'path'
        marker.id = 0
        marker.type = Marker.LINE_STRIP
        marker.action = Marker.ADD
        marker.scale.x = 0.03
        marker.color.a = 1.0
        marker.color.b = 1.0
        
        for gx, gy in grid_path:
            wx, wy = self.grid_to_world(gx, gy)
            marker.points.append(Point(x=wx, y=wy, z=0.05))
            
        marker_array.markers.append(marker)
        self.marker_pub.publish(marker_array)
        
    def publish_stats(self, algo_name):
        """Publish planning statistics"""
        stats_msg = String()
        stats_msg.data = (
            f"Algorithm: {algo_name}\n"
            f"Path Length: {self.stats['path_length']} cells\n"
            f"Nodes Explored: {self.stats['nodes_explored']}\n"
            f"Time: {self.stats['time_ms']:.2f} ms"
        )
        self.stats_pub.publish(stats_msg)

def main(args=None):
    rclpy.init(args=args)
    node = SwarmPathfinder()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:

if __name__ == '__main__':

"""
Generate ArUco markers for swarm robotics
Creates marker images and their 3D models for Gazebo
"""

import cv2
import numpy as np
import os

class ArUcoMarkerGenerator:
    def __init__(self):
        self.dictionary = cv2.aruco.getPredefinedDictionary(cv2.aruco.DICT_6X6_250)
        self.marker_size = 200  # pixels
        self.output_dir = os.path.expanduser('~/swarm_robotics_ws/src/swarm_pathfinder/markers/')
        os.makedirs(self.output_dir, exist_ok=True)
        
    def generate_marker(self, marker_id, size=200):
        """Generate a single ArUco marker"""
        marker_image = np.zeros((size, size), dtype=np.uint8)
        marker_image = cv2.aruco.generateImageMarker(
            self.dictionary, marker_id, size, marker_image, 1)
        
        # Add white border
        border_size = 20
        marker_with_border = np.ones((size + 2*border_size, size + 2*border_size), dtype=np.uint8) * 255
        marker_with_border[border_size:border_size+size, border_size:border_size+size] = marker_image
        
        return marker_with_border
    
    def generate_robot_markers(self):
        """Generate markers for each robot"""
        robots = {
            'robot_1': {'id': 0, 'name': 'Leader'},
            'robot_2': {'id': 1, 'name': 'Follower_1'},
            'robot_3': {'id': 2, 'name': 'Follower_2'},
            'robot_4': {'id': 3, 'name': 'Follower_3'},
            'pickup_station': {'id': 10, 'name': 'Pickup_Point'},
            'drop_station': {'id': 11, 'name': 'Drop_Point'},
            'obstacle_1': {'id': 20, 'name': 'Obstacle_1'},
            'obstacle_2': {'id': 21, 'name': 'Obstacle_2'},
        }
        
        for robot_key, robot_info in robots.items():
            marker = self.generate_marker(robot_info['id'])
            
            # Save as image
            filename = f"{self.output_dir}/marker_{robot_info['id']}_{robot_info['name']}.png"
            cv2.imwrite(filename, marker)
            
            # Create visualization with ID text
            display = cv2.cvtColor(marker.copy(), cv2.COLOR_GRAY2BGR)
            cv2.putText(display, f"ID:{robot_info['id']} - {robot_info['name']}",

        self.generate_mosaic(robots)

            row = i // cols
            col = i % cols
            
            marker = self.generate_marker(robot_info['id'], 200)
            
            y_start = row * 250 + 25
            x_start = col * 250 + 25
            
            mosaic[y_start:y_start+200, x_start:x_start+200] = marker
            
            # Add label

    def create_gazebo_models(self):

        # Generate marker image

    <name>Swarm Robotics</name>

#!/usr/bin/env python3
"""
ArUco Marker Detector for Swarm Robotics
Detects markers and publishes their positions
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image, CameraInfo
from geometry_msgs.msg import PoseStamped, TransformStamped
from visualization_msgs.msg import Marker, MarkerArray
from tf2_ros import TransformBroadcaster
import cv2
from cv_bridge import CvBridge
import numpy as np
import tf_transformations

class ArUcoDetector(Node):
    def __init__(self):
        super().__init__('aruco_detector')
        
        # Subscribers
        self.image_sub = self.create_subscription(
            Image, '/camera/image_raw', self.image_callback, 10)
        self.camera_info_sub = self.create_subscription(
            CameraInfo, '/camera/camera_info', self.camera_info_callback, 10)
        
        # Publishers
        self.marker_pub = self.create_publisher(
            MarkerArray, '/detected_markers', 10)
        self.pose_pub = self.create_publisher(
            PoseStamped, '/marker_poses', 10)
        
        # TF Broadcaster
        self.tf_broadcaster = TransformBroadcaster(self)
        
        # ArUco setup
        self.dictionary = cv2.aruco.getPredefinedDictionary(cv2.aruco.DICT_6X6_250)
        self.parameters = cv2.aruco.DetectorParameters()
        self.detector = cv2.aruco.ArucoDetector(self.dictionary, self.parameters)
        
        # Camera parameters
        self.camera_matrix = None
        self.dist_coeffs = None
        self.marker_size = 0.2  # 20cm markers
        
        # CV Bridge
        self.bridge = CvBridge()
        
        # Marker assignments
        self.marker_names = {
            0: 'robot_1_leader',
            1: 'robot_2_follower',
            2: 'robot_3_follower',
            3: 'robot_4_follower',
            10: 'pickup_station',
            11: 'drop_station',
            20: 'obstacle_1',
            21: 'obstacle_2'
        }
        
        self.get_logger().info('🎯 ArUco Detector Ready!')
        
    def camera_info_callback(self, msg):
        """Get camera calibration"""
        if self.camera_matrix is None:
            self.camera_matrix = np.array(msg.k).reshape(3, 3)
            self.dist_coeffs = np.array(msg.d)
            self.get_logger().info('📷 Camera calibrated!')
        
    def image_callback(self, msg):
        """Process image and detect markers"""
        try:
            # Convert ROS image to OpenCV
            cv_image = self.bridge.imgmsg_to_cv2(msg, desired_encoding='bgr8')
            
            # Detect markers
            corners, ids, rejected = self.detector.detectMarkers(cv_image)
            
            if ids is not None and self.camera_matrix is not None:
                # Draw detected markers
                cv2.aruco.drawDetectedMarkers(cv_image, corners, ids)
                
                # Estimate pose
                rvecs, tvecs, _ = cv2.aruco.estimatePoseSingleMarkers(
                    corners, self.marker_size, self.camera_matrix, self.dist_coeffs)
                
                # Publish marker data
                self.publish_markers(ids, corners, rvecs, tvecs)
                
                # Show detection
                for i in range(len(ids)):
                    cv2.aruco.drawDetectedMarkers(cv_image, corners, ids)
                    cv2.drawFrameAxes(cv_image, self.camera_matrix, 
                                    self.dist_coeffs, rvecs[i], tvecs[i], 0.1)
                    
                    # Add label
                    marker_id = ids[i][0]
                    name = self.marker_names.get(marker_id, f'Unknown_{marker_id}')
                    corner = corners[i][0][0]
                    cv2.putText(cv_image, f"{name} (ID:{marker_id})", 
                              (int(corner[0]), int(corner[1] - 10)),
                              cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)
            
            # Show image
            cv2.imshow('ArUco Detection', cv_image)
            cv2.waitKey(1)
            
        except Exception as e:
            self.get_logger().error(f'Error in detection: {e}')
    
    def publish_markers(self, ids, corners, rvecs, tvecs):
        """Publish detected marker information"""
        marker_array = MarkerArray()
        
        for i in range(len(ids)):
            marker_id = ids[i][0]
            
            # Create visualization marker
            marker = Marker()
            marker.header.frame_id = 'camera'
            marker.header.stamp = self.get_clock().now().to_msg()
            marker.ns = 'aruco_markers'
            marker.id = marker_id
            marker.type = Marker.CUBE
            marker.action = Marker.ADD
            
            # Position
            marker.pose.position.x = float(tvecs[i][0][0])
            marker.pose.position.y = float(tvecs[i][0][1])
            marker.pose.position.z = float(tvecs[i][0][2])
            
            # Orientation from rotation vector
            rot_matrix = cv2.Rodrigues(rvecs[i][0])[0]
            quaternion = tf_transformations.quaternion_from_matrix(
                np.vstack([np.hstack([rot_matrix, np.zeros((3,1))]),
                          [0, 0, 0, 1]]))
            
            marker.pose.orientation.x = quaternion[0]
            marker.pose.orientation.y = quaternion[1]
            marker.pose.orientation.z = quaternion[2]
            marker.pose.orientation.w = quaternion[3]
            
            # Size and color
            marker.scale.x = self.marker_size
            marker.scale.y = self.marker_size
            marker.scale.z = 0.01
            
            # Color based on marker type
            if marker_id < 10:  # Robot markers
                marker.color.r = 0.0
                marker.color.g = 1.0
                marker.color.b = 0.0
            elif marker_id < 20:  # Station markers
                marker.color.r = 1.0
                marker.color.g = 1.0
                marker.color.b = 0.0
            else:  # Obstacle markers
                marker.color.r = 1.0
                marker.color.g = 0.0
                marker.color.b = 0.0
            
            marker.color.a = 0.8
            marker_array.markers.append(marker)
            
            # Publish TF for each marker
            t = TransformStamped()
            t.header.stamp = self.get_clock().now().to_msg()
            t.header.frame_id = 'camera'
            t.child_frame_id = f'aruco_marker_{marker_id}'
            t.transform.translation.x = float(tvecs[i][0][0])
            t.transform.translation.y = float(tvecs[i][0][1])
            t.transform.translation.z = float(tvecs[i][0][2])
            t.transform.rotation.x = quaternion[0]
            t.transform.rotation.y = quaternion[1]
            t.transform.rotation.z = quaternion[2]
            t.transform.rotation.w = quaternion[3]
            
            self.tf_broadcaster.sendTransform(t)
            
            # Log detection
            name = self.marker_names.get(marker_id, f'Unknown')
            self.get_logger().debug(f'Detected: {name} at ({tvecs[i][0][0]:.2f}, {tvecs[i][0][1]:.2f})')
        
        if marker_array.markers:
            self.marker_pub.publish(marker_array)

def main(args=None):
    rclpy.init(args=args)
    detector = ArUcoDetector()
    
    try:
        rclpy.spin(detector)

        pass
    finally:
        cv2.destroyAllWindows()
        detector.destroy_node()

if __name__ == '__main__':
    main()

    def path_to_commands(self, path):
        """Convert path to motor commands"""
        commands = []
        for i in range(len(path)-1):
            dr = path[i+1][0] - path[i][0]
            dc = path[i+1][1] - path[i][1]
            
            if dr == 1: cmd = "FORWARD"
            elif dr == -1: cmd = "BACKWARD"
            elif dc == 1: cmd = "RIGHT"
            elif dc == -1: cmd = "LEFT"
            
            commands.append(cmd)
        return commands
